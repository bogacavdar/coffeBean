# CoffeBean 3B görsel denemesi (Godot 4.7.2)

Oyun kodu değil; 3B tarzı, kamera geçişini ve karakter hareketini göstermek için.
- Dükkan sahnesi, barista, müşteri; müşteriye tıklayınca kamera tezgâha yaklaşır, kahve fincana akar, "Teslim et" ile müşteri gider.
- Mobilya ve dekor: KayKit Furniture Bits (CC0, kits/KayKit_LICENSE.txt). Makine, öğütücü, tezgâh ve karakterler `main.gd` içinde kurulur.
- Windows çıktısı: `godot --headless --path . --export-release "Windows Desktop" build/CoffeBean3B_Deneme.exe`
