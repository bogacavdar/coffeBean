# CoffeBean birinci şahıs denemesi (Godot 4.7.2)

Oyun kodu değil; birinci şahıs hissini ve espresso adımlarını göstermek için. Ana sahne `fp.tscn` (`fp.gd`).
- WASD yürü, fare bak, E / sol tık etkileşim, Boşluk tamam, R kaşık, Esc fareyi bırakır.
- Espresso (belge §5, "Birinci şahıs espresso"): doğru portafiltre (tek/double) → terazide doz + ince ayar → iğneyle dağıtma → temperleme (su terazisi) → çevirerek kilitle → doğru fincan → gram + renk izleyerek çekim → servis → telveyi boşalt.
- Kural 9: temperleme halkaları ve çekim göstergesi hızla orantılı.
- Mobilya: KayKit Furniture Bits (CC0, kits/KayKit_LICENSE.txt).
