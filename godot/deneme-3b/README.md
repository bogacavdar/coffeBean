# CoffeBean birinci şahıs denemesi (Godot 4.7.2)

Oyun kodu değil; birinci şahıs hissini göstermek için. Ana sahne `fp.tscn` (`fp.gd`).
- WASD yürü, fare bak, E ya da sol tık etkileşim, Esc fareyi bırakır.
- Espresso elle: portafiltreyi al → öğütücüde basılı tutup 18 g'da bırak → temperde basılı tutup 15 kg'da bırak → portafiltreyi tak → fincanı koy → çekimi başlat, 27,5 sn'de durdur → fincanı al → müşteriye ver.
- Göstergelerin renkli bölgeleri Kural 9'a göre ibre hızıyla orantılı.
- `main.tscn`: önceki izometrik deneme (artık kullanılmıyor).
- Mobilya: KayKit Furniture Bits (CC0, kits/KayKit_LICENSE.txt).
